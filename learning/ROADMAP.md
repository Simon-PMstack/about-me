## Roadmap

### Phase 1 - Data foundations (weeks 1-4)
- [ ] SQL fundamentals (joins, aggregations, subqueries)
- [ ] Spreadsheet/BI basics: pivot tables, basic charts
- [ ] Python basics: variables, loops, functions
- Experiment: pull a small dataset (CSV) and answer 3 business questions with it

### Phase 2 - Python for data (weeks 5-8)
- [ ] pandas: loading, filtering, grouping, merging
- [ ] Data cleaning: missing values, duplicates, types
- [ ] Intro visualization: matplotlib/seaborn basics
- Experiment: clean a messy dataset and summarize findings in one chart

### Phase 3 - Analytics & storytelling (weeks 9-12)
- [ ] Exploratory data analysis (EDA) workflow
- [ ] Intro statistics: distributions, correlation vs causation
- [ ] Dashboarding basics (e.g. Power BI)
- Experiment: build a one-page dashboard or report from phase-2 data

### Phase 4 - AI & automation (weeks 13-16)
- [ ] Intro machine learning concepts: supervised vs unsupervised
- [ ] LLM basics: prompting, use cases, limits
- [ ] Automation: scripts, APIs, scheduled tasks
- Experiment: automate one repetitive task from my PM work
